Kupe exposes the same `/v1` API as MCP tools at **`http://mcp.kupe.in/mcp`**. Every tool call sends your key — nothing is stored on the MCP host.

Use a project API key (`sk-kupe-...`). HTTP 401 if the `Authorization` header is missing.

Opening the URL in a browser returns **Not Acceptable** — this is streamable MCP (`Accept: text/event-stream`), not a web page. Use Cursor, Claude Code, Codex, or another MCP client.

## Remote (recommended)

No local Python. Point the client at the hosted server:

```json
{
  "mcpServers": {
    "kupe": {
      "url": "http://mcp.kupe.in/mcp",
      "headers": {
        "Authorization": "Bearer sk-kupe-YOUR_KEY"
      }
    }
  }
}
```

Replace `sk-kupe-YOUR_KEY` with the same key you use in the dashboard or SDK.

## Cursor

1. Open **Cursor Settings → MCP**.
2. Add a server named `kupe` with the JSON above (or merge `mcpServers.kupe` into `~/.cursor/mcp.json`).
3. Restart MCP. Tools should list under `kupe`.

Project-level: `.cursor/mcp.json` in the repo with the same `mcpServers` object.

## Claude Code

```bash
claude mcp add --transport http kupe http://mcp.kupe.in/mcp \
  --header "Authorization: Bearer sk-kupe-YOUR_KEY"
```

Confirm with `claude mcp list`.

## Codex

Add the same remote block to your Codex MCP config (`mcp.json`):

```json
{
  "mcpServers": {
    "kupe": {
      "url": "http://mcp.kupe.in/mcp",
      "headers": {
        "Authorization": "Bearer sk-kupe-YOUR_KEY"
      }
    }
  }
}
```

## Stdio fallback

If you need a local process instead of the hosted URL:

```json
{
  "mcpServers": {
    "kupe": {
      "command": "uvx",
      "args": ["kupe-mcp"],
      "env": {
        "KUPE_API_KEY": "sk-kupe-YOUR_KEY"
      }
    }
  }
}
```

From a clone of `kupe-mcp`: `python -m app.server --mcp` with `KUPE_API_KEY` in the environment.

## Safety

- Never log or commit the key. Clipboard toasts in the dashboard warn on copy.
- Phone **buy** and **delete** tools require `confirm=true` — they are billed or hard to undo.
- Voice clone / delete are JWT-oriented on the API; prefer the dashboard for those, or a user token.

The MCP surface covers agents, campaigns, inbound, phones, voices, billing/usage, logs, tools, Composio, and databases. REST details live in the [API playground](/playground).
