description: Move integrations from api.kupe.in (Milli) to the Kupe platform at x.kupe.in. Hub is the console, not the REST host.
---

Milli (`milli_ai_backend`) was the previous public API, hosted at **`https://api.kupe.in`**. The Kupe platform (`kupe-backend`) is a new product: new auth, new resource model, new paths. There is no drop-in URL rewrite.

<Warning>
  **`hub.kupe.in` is the product UI**, not the REST base. Calling Hub as if it were the API will not work. REST and WebSocket live on **`x.kupe.in`**.
</Warning>

## Why migrate

| | Milli | Kupe |
| --- | --- | --- |
| Host | `https://api.kupe.in` | `https://x.kupe.in` |
| Console | `https://app.kupe.in` (legacy) | [`https://hub.kupe.in`](https://hub.kupe.in) |
| Auth | `x-api-key` (opaque `token_urlsafe` string) or a Supabase user JWT | `Authorization: Bearer sk-kupe-...` (project key) or a Hub JWT |
| Agent shape | Nested `agent` + `agent_model_config` + `tts_config` + `transcriber_config` | Flat `name`, `system_prompt`, `greeting`, `config.*` |
| IDs | UUIDs | Prefixed (`agt_`, `org_`, `prj_`, `tel_`, `bat_`, `sess_`) |
| Outbound | `POST /api/call/create_call` (query params) | One-contact **batch**, or a campaign |
| Inbound | `POST /api/v1/phone/mapping` | **Inbound deployment** |
| SDK | None first-party | [`kupe`](/sdk/python) / [`kupe-sdk`](/sdk/typescript) |
| Agents in the IDE | Call Milli yourself | [Kupe MCP](/kupe-mcp) at `http://mcp.kupe.in/mcp` |

Milli keys, agent UUIDs, phone rows, and campaign IDs **do not work** on `x.kupe.in`. Recreate keys in Hub, then recreate (or re-link) agents, numbers, and campaigns.

## Verified hosts

These values are from live config, not marketing copy.

| Role | Milli | Kupe |
| --- | --- | --- |
| Public REST | `https://api.kupe.in` (`config.json` → `server.base_url`) | `https://x.kupe.in` (`public_api_url` / docs OpenAPI `servers`) |
| Product UI | Legacy app host | `https://hub.kupe.in` (`frontend_origin`) |
| Web realtime WS | `wss://api.kupe.in/api/call/web-media-stream` | `wss://x.kupe.in/agents/v1/realtime` |
| Telephony media WS | `wss://api.kupe.in/api/call/{provider}-media-stream/...` | `wss://x.kupe.in/agents/v1/media` (ticketed; not a public DIY URL) |
| MCP | — | `http://mcp.kupe.in/mcp` |
| Docs | — | `https://docs.kupe.in` |

Milli `api_specification.yaml` lists `https://api.inavlabs.com` as a server. Production traffic used **`api.kupe.in`** (`config.json`, CORS allow-list, Plivo answer URLs).

## Rewrite order

1. Create a Hub account and a **project API key** (`sk-kupe-...`). See [Authentication](/auth).
2. Change the base URL to `https://x.kupe.in`. SDKs join `/v1` for you.
3. Recreate the agent (`POST /v1/orgs/{org_id}/projects/{project_id}/agents`). Map prompt → `system_prompt`, welcome message → `greeting`, voice → `tts_voice_id` or catalog name. See [Prompting](/guides/prompting).
4. Attach numbers as **telephony accounts**. India numbers still need [KYC](/guides/kyc). Bind inbound with a [deployment](/guides/inbound).
5. Replace `POST /api/call/create_call` with a one-contact [campaign](/guides/campaigns) (or MCP `trigger_outbound_call`).
6. Move tools to **org tools** (webhook / MCP / Composio), then attach them to the agent. See [Tools](/guides/tools).
7. Point web testers at [Realtime](/realtime), not Milli media sockets.

<Note>
  Provider answer/hangup URLs are **not** in the public OpenAPI. Kupe-managed Plivo numbers are wired to `https://x.kupe.in/v1/telephony/plivo/inbound` on purchase. Do not keep Plivo applications aimed at `https://api.kupe.in/api/call/plivo-incoming_call`.
</Note>
