---
title: MCP instead of calling Milli
description: kupe-mcp talks to x.kupe.in with your Bearer key. It does not wrap Milli.
---

[Kupe MCP](/kupe-mcp) (`http://mcp.kupe.in/mcp`) forwards every tool call to **`https://x.kupe.in`** with the same `Authorization: Bearer sk-kupe-...` header. It will not accept a Milli `x-api-key` and it will not call `api.kupe.in`.

If your agent was “just POST Milli `/api/call/create_call` from the IDE”, switch the MCP server to Kupe and use the tools below.

## Milli habit → MCP tool

| You used to… | Use |
| --- | --- |
| `POST /api/v1/agents` | `create_agent` (`org_id`, `project_id`, `name`, `system_prompt`, `greeting`, …) |
| List / get / patch agent | `list_agents`, `get_agent`, `update_agent`, then `commit_agent` for versions |
| `POST /api/call/create_call` | `trigger_outbound_call` (creates a one-contact batch and starts it) |
| Phone mapping | `create_inbound_deployment` |
| Campaigns + people groups | `create_campaign`, `create_recipient_list`, contacts helpers |
| `GET /api/v1/phone/plivo/available-numbers` + rent | `list_phone_numbers`, `buy_phone_number` (`confirm=true`) |
| UCC (new on Kupe) | `list_ucc_complaints`, `get_ucc_summary`, `submit_ucc_proof` |
| Call logs | `list_sessions`, `get_session_transcript`, `get_session_recording` |
| Wallet | `get_billing_wallet`, `list_billing_invoices` |
| Files / RAG | `create_knowledge_base`, file upload, `search_knowledge_base` |
| Tool endpoint defs | `create_webhook_tool` / `create_mcp_tool` |
| Composio | `composio_*` tools |
| Read this site | `list_docs_toc`, `search_docs`, `get_docs_page` |

Confirm-gated: **buy phone**, **delete phone**, **delete cloned voice**. The model must not invent `confirm=true`.

## Do not

- Point MCP at `https://api.kupe.in`
- Mix Milli agent UUIDs into Kupe tools
- Use `https://docs.kupe.in/mcp` as the platform MCP (that path is docs-search, not `kupe-mcp`)
